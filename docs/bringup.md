# 実機の立ち上げ手順

ファームウェアは `firmware/firmware` で `cargo run --release`(ST-Link と probe-rs が必要。初回は `cargo install probe-rs-tools --locked`)。PC 側は `firmware` で `cargo run -p host --release`。

上から順に行い、各項目の合格条件を満たしてから次へ進む。

1. **Bluepill 単体**
   - [ ] PC13 の LED が約1秒周期で点滅する。
   - [ ] PC に `voyager-carrier`(VID 0x16C0 / PID 0x27DD)として認識される。認識されない場合は、Bluepill の R10 を確認し、PA12–3.3V 間に 1.8kΩ を付ける(基板の R_USB)。
2. **通信**
   - [ ] host を起動すると、ステータス行が `LINK` になり、テレメトリが更新される(20Hz)。
   - [ ] USB 給電だけでは電池電圧が 0V のため `estop LATCHED` と表示される(正常)。
   - [ ] host を止めると、200ms 以内にテレメトリの faults に `0x08`(指令タイムアウト)が立つ(host 再起動後に CSV で確認)。
3. **PWM(モーターは外したまま、電池を接続)**
   - [ ] 起動直後、非常停止の解除ボタン(既定は Start)を押し、スティックを中立にすると `estop ok` になる。
   - [ ] 前進入力で、左モーターの IN1(PB6)が High 固定、IN2(PB7)が反転 PWM(20kHz)になる。後退入力では IN1 と IN2 が入れ替わる。テスターかロジックアナライザで確認する。
4. **駆動モーター(車輪を浮かせる)**
   - [ ] 前進で左右とも前に回る。逆なら、そのモーターの2本の線を入れ替える。
   - [ ] 前進でテレメトリの enc_left / enc_right が増える。減る場合はエンコーダの A と B を入れ替える。
5. **把持モーター**
   - [ ] 閉じるボタン(既定は South)で閉じる向きに動く。逆ならモーターの線を入れ替える。
   - [ ] 閉じる向きで enc_grip が増える。減る場合は `robot-core/src/gripper.rs` の `DEFAULT_GRIPPER.dir` を `-1` にする。
   - [ ] 初回の閉じる操作では、先に開ききって原点を取り(状態 Opening → Open)、その後に閉じる。
6. **非常停止**
   - [ ] 走行中に非常停止を押すと全モーターが止まり、`estop LATCHED` になる。
   - [ ] 非常停止を戻しても、解除ボタンを押してスティックを中立に戻すまで動かない。
7. **超音波センサー**
   - [ ] 壁から 300mm の位置で、該当センサーの値が 280〜320mm になる。値が 0 のときは配線(TRIG / ECHO)を確認する。

調整(把持力、カウント/mm、箱数のしきい値)は `docs/tuning.md` を参照。
