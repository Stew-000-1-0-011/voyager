# 大会当日の確認リスト

## 出発前
- [ ] 電池(3S)を満充電にする。予備の電池も充電する。
- [ ] 運営への申告を済ませた(二次電池の使用。無線を使う場合はその許可)。
- [ ] 予備部品:Bluepill、DRV8871、ヒューズ(10A)、USB ケーブル、USB アイソレータ、XH コネクタ、結束バンド、ホットボンド。
- [ ] 工具:ドライバー、六角レンチ、テスター、はんだごて、ラジオペンチ、ニッパー。
- [ ] ノート PC に host をビルド済み(`cargo build -p host --release`)。ゲームパッドと充電ケーブル。

## 試合前(毎回)
- [ ] 電池電圧が 1セル 4.0V 以上(3S で 12.0V 以上)。
- [ ] ヒューズが入っている。メインスイッチが OFF の状態で電池をつなぐ。
- [ ] 非常停止ボタンが押せる位置にあり、押すと止まる。
- [ ] USB ケーブルとアイソレータがつながり、host のステータスが `LINK`。
- [ ] 非常停止を解除し(Start)、`estop ok` になる。
- [ ] 把持の原点合わせ:開くボタンで開ききり、状態が Open になる。
- [ ] スタートゾーンに完全に入っている。アームは閉じた状態(幅が小さい)。

## 試合中の注意
- スラロームでは保持は最大2個。木枠の側面に意図的に当てない。
- ゴールゾーンの黒い領域は、ノーツを持っているときだけ入る。置いたらすぐ出る。
- 止まらなくなったら非常停止。リトライ時は保持しているノーツをノーツエリアに戻す。
