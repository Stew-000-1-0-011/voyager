# 基板外の配線

このファイルは `mechanical/harness.py` が生成する。手で編集しない。図は `mechanical/images/harness.png`。

- ケーブルはアルミフレームの上面か外面に沿わせ、結束バンドで 50〜80mm おきに留める。電装トレイの上では基板とモジュールの間をゆるく回す。
- 長さは図の経路に両端の余裕 60mm を足して 50mm 単位に切り上げた目安。実物に当てて切る。
- 電源の流れ:電池 → XT60 → ヒューズ 10A → メインスイッチ → 非常停止 → 電源分岐(レバー式コネクタ) → DRV8871 ×3 の電源端子と基板の J_PWR。電池の − は電源分岐の − へ直接つなぐ。
- モーターの 6P ケーブルは中間クロス材の前で、M1/M2(ドライバへ)とエンコーダ4本(基板へ)に分ける。
- モジュールの置き場所(トレイ上、基板の前): DRV_L / DRV_G / DRV_R を左から順に、降圧モジュールを右端。メインスイッチと電源分岐はトレイの左奥。
