# 調整手順

調整した値は `firmware/robot-core/src/gripper.rs` の `DEFAULT_GRIPPER` に反映し、`cd firmware && cargo test -p robot-core` が通ることを確認してからコミットする。数値はテレメトリ(host の表示、または `logs/telemetry-*.csv`)で読む。

## 1. 把持のカウント/mm

1. 起動後、開くボタンで開ききる(状態 Open)。このときの enc_grip を記録する(a)。
2. 箱を挟まずに閉じるボタンで閉じきる(状態 Holding)。enc_grip を記録する(b)。
3. ノギスで、開ききりと閉じきりのパッド内面の間隔を測る(片側の移動量 = (開いた幅 − 閉じた幅) / 2)。
4. カウント/mm = |b − a| / 片側の移動量。既定値は 63(概算)。

## 2. 把持力(目標:片側 10N)

1. アームの間にばねばかりのフックを挟み、閉じる。
2. 保持状態(Holding)で、ばねばかりを引いてパッドが滑り出す直前の値を読む。保持力 = 2面 × 摩擦 × 挟む力 なので、挟む力 ≈ 読み ÷(2 × 0.8)。
3. 挟む力が 10N 前後になるよう `hold_cmd` を調整する(既定 200)。閉じる途中の力は `close_cmd`(既定 500)で、箱が潰れない範囲で決める。
4. DRV8871 の電流上限抵抗(把持用は約62kΩ = 約1A)も上限として効く。

## 3. 箱数のしきい値

1. 箱2個を挟んで Holding にし、(enc_grip − 開ききりの値) × dir を記録する(d2)。
2. 箱1個で同じく記録する(d1)。何も挟まない閉じきりも記録する(d0)。
3. `two_box_max = (d2 + d1) / 2`、`one_box_max = (d1 + d0) / 2` にする。

## 4. 電池のしきい値の確認

安定化電源を電池の代わりにつないで確認する。
- 10.4V:faults に `0x02`(電池低下)が立ち、走行の出力が 50% に制限される。
- 9.8V:faults に `0x04`(電池危険)が立ち、全モーターが止まる。再起動するまで解除されない。
- 0V(非常停止):`estop LATCHED` になる。
