# ユニバーサル基板 配置・結線

このファイルは `gen_perfboard.py` が `netlist.py` から生成する。手で編集しない。

## Bluepill の向きの確認

- ソケット J_BP_A のピン1((19,4))に挿さる端子が **3V3**、J_BP_B のピン1((13,4))が **VB** であること。USB コネクタは基板の後端(行の大きい側)を向く。
- 実物のシルク印刷で確認する。違う場合は、ハンダ付けの前に `netlist.py` の `BLUEPILL_ROW_A` / `BLUEPILL_ROW_B` と `PLACEMENT` を直して再生成する。

## 配線経路

配線はすべてはんだ面で行う。電源(VBAT、GND)も基板上の電流は小さい(降圧モジュールの入力と電圧測定だけ)ので、信号と同じ線で引く。作業順:(1)はんだ面の裸配線(すずめっき線を穴に沿って這わせ、通る穴ごとにはんだ付け)、(2)はんだ面の被覆線(耐熱の被覆線、たとえば AWG26〜30 の ETFE ラッピング線を、裸配線の上から穴の列に沿って這わせる。はんだ付けは両端だけで、端はピンのはんだの上か、裸配線の上に付ける。裸配線や他の被覆線とは直角に交差してよいが、途中で他のピンのはんだの上は通さない)。ポリウレタン線ははんだごての熱で被覆が溶けるので、交差に使わない。図は `images/perfboard_top.png`(部品面)、`images/perfboard_bottom.png`(はんだ面の裸配線)、`images/perfboard_wires.png`(はんだ面の被覆線)。はんだ面の図は左右反転。

裸配線 41 本、被覆線 8 本。
