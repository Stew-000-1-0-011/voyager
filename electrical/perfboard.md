# ユニバーサル基板 配置・結線

このファイルは `gen_perfboard.py` が `netlist.py` から生成する。手で編集しない。

## Bluepill の向きの確認

- ソケット J_BP_A のピン1((23,10))に挿さる端子が **PB12**、J_BP_B のピン1((17,10))が **VB** であること。USB コネクタは基板の後端(行の大きい側)を向く。
- 実物のシルク印刷で確認する。違う場合は、ハンダ付けの前に `netlist.py` の `BLUEPILL_ROW_A` / `BLUEPILL_ROW_B` と `PLACEMENT` を直して再生成する。

## 導通確認

- 結線表の各行を、テスターの導通モードで確認して ✓ を付ける。
- 次の組み合わせが **短絡していない** ことを確認する(電源を入れる前に必ず行う)。
  - ☐ VBAT と GND
  - ☐ +5V と GND
  - ☐ +5V_BP と GND
  - ☐ +3V3 と GND
  - ☐ VBAT と +5V
